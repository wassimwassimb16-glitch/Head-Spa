# Recreate Head Spa Hradec Králové

## What I’ll build

- Recreate the full dark, gold-accented homepage with the same hero imagery, logo treatment, announcement, services, team, reviews, contact details, and footer.
- Match the responsive mobile and desktop layouts, typography, spacing, navigation, and section order closely.
- Rebuild service category filters, service detail popups, the reservation form, and key buttons and external links.
- Add the linked gift voucher, pre-visit information, privacy, and terms pages so navigation does not lead to missing pages.

## Technical details

- Use the existing React application structure and local copies of the source site’s publicly served visual assets.
- Keep all colors and visual roles in the shared design system, using the original Montserrat and Ephesis typefaces.
- Give each page its own search and social metadata.
- Validate the result in desktop and mobile browsers, including menus, filters, dialogs, and form states.

## Known limitation

- The original site’s private form-delivery system is not exposed publicly. The recreated forms will match the experience, but live delivery will remain unverified until a destination is provided.
